ppt-maker 使用指南

在浏览器里点一点、写一句"想怎么改"，由 Claude Code 或 Codex 帮你改幻灯片，最后导出成可编辑的 PPTX。

1. 准备

  • 装好 Python 3 和一个浏览器（Chrome / Edge）。
  • 装好 Claude Code 或 Codex CLI，任选其一，或两个都装。
  • 幻灯片存在你打开 agent 的目录下：decks/<名字>/deck.html。

2. 启动

用 Claude Code

  1. 第一次用之前，先运行一次：
    python ppt/server.py --install-claude
    之后在任意目录都能用 /ppt。
  2. 在终端打开 Claude Code。
  3. 输入 /ppt 我的演讲。
  4. 浏览器会自动打开幻灯片。这份稿子是新的话，Claude 会先写一份 3–6 页的初稿。
  5. 之后你在浏览器里的每个操作都会自动送到 Claude，在终端里也可以直接跟它说话。

用 Codex

  1. 第一次用之前，先运行一次：
    python ppt/server.py --install-codex
    然后把它打印出来的设置加进 ~/.codex/config.toml，再重开 Codex。
  2. 输入 $ppt 我的演讲（Codex 的技能以 $ 开头）。
  3. Codex 会一直等着浏览器里的操作。想跟它说话就按 Esc，说完让它"继续"。
  4. 15 分钟没有操作它会自动停止监听，说"继续"就会恢复。

同一份稿子一次只开一边（Claude 或 Codex），不然两边可能都去处理同一个操作。页面右上角会显示当前是谁在线。

3. 在浏览器里怎么改

想做什么怎么做
改某一块点一下这一块，按 Enter 或点 💬 问 Claude，写下想怎么改，再按 Enter 发送。
改一片区域 / 在空白处加东西在页面上拖出一个框，写下想要什么。
只改一句话双击文字进入编辑，选中那句话后右键，写下怎么改。只有这句会被改动。
自己动手改双击改字；拖动挪位置；用工具栏改颜色、字号、加粗。Delete 删除，↶ / ↷ 撤销和重做。
画个草图让它照着做点 ✎ 草图 在当前页上画，或点 +草图页 新建一页来画。可以加文字标注。
攒一批再一起发写意图时按 Ctrl+Enter 加入清单。攒好后点 📝 清单，写一句总体说明，一次发出。
给它参考资料点 📚 知识库，放进 PDF、图片、网址或旧稿子。改稿时它会参考这些资料。
沿用以前的稿子点 导入，选 .pptx / .html / .zip，或者贴一个网址。
交付点 导出 PPT，得到能在 PowerPoint 里继续编辑的 .pptx。插图和图标也是原生形状，里面的文字、颜色、大小和位置都能直接改；渐变、滤镜这类转不了的部分才单独转成图片，并在导出报告里列出来。

4. 页面上的框是什么意思

紫色虚线框已放进清单，还没发出。
橙框已发出，正在排队。
蓝框agent 正在处理。
绿框改完了，旁边的气泡里是它的说明。点气泡上的 × 关掉一个；点顶栏的 ✓ 清除标记 一次关掉全部绿框。

agent 有问题要问你时，会在气泡里提问，直接在气泡里回答就行。

5. 常见问题

现象怎么办
页面显示 agent 离线Claude：在终端里让它重新监听。Codex：对它说"继续"。
Codex 报 blocked by policyconfig.toml 里没加 [windows] sandbox = "unelevated"。加上后重开 Codex。
Codex 抓不到网页，或写不进全局知识库按第 2 步，把 network_access 和 writable_roots 两项也加进 config.toml。
改坏了点 ↶ 撤销。撤销 agent 的修改后，它不会自己再改回去。
想关掉跟 agent 说"关掉 ppt"就行。稿子保存在 decks/<名字>/，下次用同一个名字打开会接着改。
