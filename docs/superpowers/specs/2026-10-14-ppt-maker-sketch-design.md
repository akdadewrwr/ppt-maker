# ppt-maker 子项目 3：手绘草图 设计

日期：2026-10-14　状态：待审阅　前置：子项目 1（核心闭环）、子项目 2（基础编辑 2a + 浮动对象 2b，见 `2026-10-14-ppt-maker-basic-editing-design.md`）

## 1. 目标与范围

**问题**：用户脑子里的版面（"标题在左上，右边一张大图，下面三列要点"）很难用一句话说清楚。框选写意图只能说"改这里"，说不清"改成什么样"。

**目标**：用户可以在幻灯片上随手画，画出来的东西有两种去处：
1. **发给 Claude**：草图连同一句话作为意图发给 Claude，由 Claude 变成正式版面或图形。草图本身不进 deck。这是"把用户的隐性想法对齐成明确内容"的主要入口。
2. **保留为笔迹**：草图作为一个浮动对象存进 deck，像 PowerPoint 的墨迹一样可以移动、缩放、改色、删除。

**使用场景**：叠在现有页上画（"这块改成这样"），以及在空白页上从头画整页布局，让 Claude 生成这一页。

**输入设备**：鼠标 / 触控板。线条需要自动平滑去抖，不做压感。

**成功标准**：用户不用写长段文字，画一个粗略布局加几个文字标注，Claude 就能做出对应的页面；用户也能把手绘标记留在幻灯片上。

**不做**（以后需要再加）：压感、形状识别（把歪圆自动变成正圆）、手写文字识别、局部擦除（按像素擦）、多页同时画、导出 pptx 时笔迹的处理（属于导出子项目）。

## 2. 交互

### 2.1 入口（顶栏）
- **✎ 草图**：在当前页（视口中露出面积最大的那一页）进入画笔模式。
- **+草图页**：在当前页之后插入一张空白页（`insertSlide` op，可撤销），并在新页上进入画笔模式。

### 2.2 画笔模式
- 只在当前这一页上覆盖一层透明画板（SVG，`viewBox="0 0 1280 720"`，随页面缩放）。其他编辑暂停：不能选中块、不能改字、不能框选。页面可以滚动，画板跟着这一页走。
- 草图工具栏（浮在这一页上方，空间不够时放在下方）：
  `画笔 · 颜色 · 粗细 · 橡皮 · T 标注 · ↶ · 清空 ┃ 发给 Claude · 保留为笔迹 · 取消`
  - 颜色：红 `#ef4444`（默认）、黑 `#111827`、蓝 `#2563eb`、绿 `#16a34a`、橙 `#f97316`。
  - 粗细：细 2px、中 4px（默认）、粗 8px。
  - **画笔**：按住拖动画线，抬笔后平滑（见 3.2）。
  - **橡皮**：点在某一笔或某个标注上，删掉整个元素（命中范围：线条两侧各 6px）。
  - **T 标注**：点一下出现输入框，Enter 确定、Esc 放弃；确定后显示为带浅色底的文字标签（20px，当前颜色）。
  - **↶**：撤销上一笔（或上一个标注、上一次橡皮删除）。**清空**：删掉这一页草图的全部内容（可用 ↶ 恢复）。
  - **取消 / Esc**：退出画笔模式。草图作为草稿留在浏览器里，下次在同一页点"✎ 草图"会恢复。
- 画笔模式中，Claude 修改了文件也不刷新页面（与正在打字相同），退出后再刷新。

### 2.3 两个出口
- **发给 Claude**：弹出与框选意图相同的输入框；可以写一句话，也可以直接 Enter（默认文字"按草图修改这一页"）。发送后退出画笔模式并清掉这页的草稿。详见第 4 节。
- **保留为笔迹**：把全部笔画和标注合成一个 `ink` 对象插入这一页，并选中它；退出画笔模式，清掉草稿。详见第 5 节。
- 草图为空时，两个出口都只提示"还没有画内容"。

## 3. 数据

### 3.1 模型
```js
sketch = { slideId, items: [
  { type: 'stroke', color: '#ef4444', width: 4, d: 'M10 20 Q…' },   // 平滑后的路径，画布像素
  { type: 'note',   color: '#ef4444', x: 300, y: 120, text: '标题' }, // 文字左上角
] }
```
- 草稿存在 localStorage：键 `ppt-sketch:<slideId>:<口令>`。存不进去（空间满、隐私模式）时画笔模式照常可用，只是没有草稿。
- 撤销栈只在内存里，退出画笔模式后清空。

### 3.2 平滑（纯函数，确定性）
1. 采集：Pointer Events；与上一点距离小于 2px 的点丢弃；坐标夹在 0–1280 / 0–720 内。
2. 简化：Ramer–Douglas–Peucker，容差 1.5px。
3. 拟合：以相邻点的中点为端点、原始点为控制点生成二次贝塞尔曲线（`M … Q …`）。只有一个点时画一个圆点（长度为 0 的线段，圆端点）。
4. 数字保留一位小数。同样的点列总得到同样的 `d`。

## 4. 发给 Claude

### 4.1 事件
```json
{ "type": "intent", "kind": "sketch", "slide": 2, "slide_id": "s-…",
  "rect": {"x":…,"y":…,"w":…,"h":…}, "cells": "…", "blocks": ["b-…", "o-…"],
  "text": "按这个布局做", "notes": ["标题", "这里放图表"], "shot": "data:image/png;base64,…" }
```
- `rect`：全部笔画和标注的外接矩形（四周留 8px，夹在画布内）。`cells` 由 `rect` 换算。
- `blocks`：与 `rect` 相交的块和对象（与框选规则相同，最内层在前）。空白页为 `[]`。
- `notes`：所有标注的原文，按添加顺序。
- `shot`：**整页**截图（1280×720，不裁剪），先截幻灯片，再把草图画在上面（标注带浅色底）。截图失败时照常发送，不带 `shot`。

### 4.2 服务端
- 事件白名单加 `notes`：字符串列表，最多 50 项，每项不超过 200 字；不符合时返回 400。
- 摘要行显示 `kind:sketch`（2b 已支持），并附上前几个标注：`notes:「标题」「这里放图表」`。

### 4.3 `ppt.md` 规则（草图意图）
- 用 Read 看截图：线条和框表示布局意图，箭头表示关系或流程，`notes` 是文字提示（以 `notes` 的原文为准，不要从图里认字）。
- 不要把手绘线条原样搬进 deck，要做成正式的块、表格、形状、箭头或图标，并遵守网格和格式规则。
- 已有页：只改 `blocks` 列出的块和对象，以及草图范围内需要新建的内容，除非用户的话另有说明。空白页（页里没有块）：按草图生成整页。
- 看不懂草图时，在回执里问一个具体问题，不要猜。

## 5. 保留为笔迹

### 5.1 格式
```html
<div class="obj" id="o-…" data-kind="ink" style="left:…px;top:…px;width:…px;height:…px">
  <svg viewBox="0 0 w h" preserveAspectRatio="none">
    <path d="…" fill="none" stroke="#ef4444" stroke-width="4" stroke-linecap="round" stroke-linejoin="round" vector-effect="non-scaling-stroke"/>
    <text x="…" y="…" font-size="20" fill="#ef4444">标题</text>
  </svg>
</div>
```
- 外框为全部内容的外接矩形，四周留 `max(粗细)/2 + 4` px；SVG 内坐标相对外框左上角。
- `vector-effect="non-scaling-stroke"`：拉伸对象时线条粗细不变。标注文字会跟随拉伸（已知取舍）。
- 标注在笔迹里不带底色。

### 5.2 op 与编辑
- 插入：复用 `insertObj`（`kind` 增加 `ink`，`html` 为上面的 SVG）；旧 deck 先 `ensureBase`（与 2b 相同）。
- 移动、缩放（Shift 保持比例）、旋转、置顶置底、删除、撤销：全部复用 2b。
- 新 op `setInkColor {color}`：把对象内所有 `path` 的 `stroke` 和 `text` 的 `fill` 设为同一颜色（绝对值，确定性）。
- 笔迹浮动栏：`颜色 · 透明度 ┃ 置顶 置底 ┃ 删除 ┃ 问 Claude`。

### 5.3 `ppt.md` 规则（笔迹）
- `data-kind="ink"` 是用户亲手画的，不要主动修改或删除。
- 用户对笔迹"问 Claude"（例如"整理成正式的流程图"）时，按笔迹的意思生成正式内容；是否删除原笔迹按用户的话决定，没说就保留。

## 6. 架构

```
ppt/
├─ sketch.js      新：纯函数（simplify / smoothPath / bounds / inkSVG / drawOnCanvas）+ 画笔模式界面（画板、草图工具栏、标注输入、草稿读写）
├─ editor.js      改：入口回调；画笔模式中暂停其他编辑并推迟刷新；"发给 Claude"复用意图队列与截图；"保留为笔迹"复用 addObj
├─ toolbar.js     改：顶栏"✎ 草图""+草图页"；ink 浮动栏
├─ ops.js         改：KINDS 加 ink；新 op setInkColor
├─ editor.css     改：画板、草图工具栏、标注样式
├─ server.py      改：notes 字段；摘要行显示 notes
└─ selftest.html / test_server.py / tests/e2e.mjs  改：测试
.claude/commands/ppt.md  改：草图意图与笔迹规则
```
注入顺序：`… ops.js → icons.js → icons-zh.js → sketch.js → toolbar.js → editor.js`。

`geom.js` 的 `hitBlocks` 现在也返回相交的对象（对象在前，块按由内到外），框选意图和草图意图都受益。

`sketch.js` 暴露 `window.PPTSketch = { simplify, smoothPath, bounds, inkSVG, drawOnCanvas, open(slide, cb) }`。`open` 返回控制对象 `{ active, close() }`；`cb` 提供 `send(sketch)`、`keep(sketch)`、`place`、`ls`、`toast`。界面代码不直接改 deck，所有 deck 修改都经 editor.js 的 op。

## 7. 出错处理

| 情况 | 处理 |
|---|---|
| 草图为空时点出口 | 提示"还没有画内容"，不发送、不插入 |
| 截图失败 | 照常发送，不带 `shot`，`notes` 和 `rect` 照带 |
| 草稿写不进浏览器 | 画笔模式照常可用，只是没有草稿 |
| 画到页面外 | 坐标夹在画布内 |
| 画笔模式中 Claude 改了文件 | 不刷新；退出画笔模式后刷新；草稿不受影响 |
| 画笔模式中当前页被删除（Claude 或撤销） | 画笔模式中页面不刷新、键盘不作用于 deck，所以这一页不会从画面上消失；退出后刷新，若该页已删除，草稿只是留在浏览器里不再被用到 |
| `notes` 不合格（服务端） | 400，页面按现有逻辑丢弃该事件并提示 |

## 8. 测试

1. **selftest**：`simplify` 与 `smoothPath` 对固定输入给出固定输出；单点生成圆点；`bounds` 含留边与夹取；`inkSVG` 输出格式（viewBox、相对坐标、non-scaling-stroke）；`insertObj` 插入 `ink`；`setInkColor` 改全部路径与文字，两份相同文档结果逐字相同。
2. **test_server**：`notes` 被存下、出现在摘要行；类型错误、超过 50 项、单项超过 200 字被拒绝。
3. **e2e**：进入画笔模式画两笔、加一个标注、↶ 撤销一笔、橡皮删一笔；Esc 退出后重新进入草稿还在；发给 Claude 得到 `kind:sketch` 意图（带整页截图与 `notes`）且草稿被清掉；保留为笔迹后 deck 出现 ink 对象，可移动、可整体改色、可撤销；画笔模式中外部改文件不刷新，退出后刷新；+草图页插入空白页并进入画笔模式；空草图点出口只提示。
4. **真实会话验收**（副本 deck，验完删除）：在空白草图页画一个布局并加标注发给 Claude，Claude 按 `ppt.md` 生成整页；在已有页上圈一块画个示意发给 Claude，只改相关块；保留一份笔迹并对它"问 Claude：整理成正式流程图"。
